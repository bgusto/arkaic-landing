What the platform does

Run

Any script, on any number of machines. A sweep runs one job per set of values, and each job gets a whole machine.

  • Machines billed by the second; start-up and idle minutes are free
  • Open-source solvers built in: OpenFOAM, SU2, CalculiX, Castro, WRF
  • Your own code on the toolchain: GCC, MPI, and the scientific libraries
  • Your own machines, with Evolve directing the work

Sample and fit

Cover a design space with a planned set of runs, then fit a surrogate model to what they returned.

  • Surrogates from many samples or from few
  • Multi-fidelity: many cheap runs and a few accurate ones in one model
  • Accuracy measured, with the error shown
  • Models are files you can keep and run anywhere

Optimize

Choose the next runs from what the earlier ones showed, for one goal or several.

  • Cheap runs steer where the costly ones go
  • Constraints and mixed variables
  • Stop, resume, or cancel a campaign at any time
  • Repeating work on a schedule, such as a daily forecast

Keep a record

Every run records exactly what ran, so a result can be repeated or cited.

  • The solver image and the exact files of your folder
  • Logs that stream while a run is going
  • Files kept per run, listed and downloaded from the terminal
  • Usage and spend by job

From the terminal or the browser

The evolve command and the web app talk to the same service. Install the command, sign in, and run the example. Sign-up happens in the browser during login, and you can buy credit there.

curl -fsSL https://evolve.arkaic.inc/install.sh | sh
evolve login
evolve init
evolve sweep -out f job.sh thickness=10,7,5

Windows: use install.ps1 from the same address.
