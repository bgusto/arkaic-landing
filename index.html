Workflows for every use case

Rocket nozzle design

Find the shape that gives the most thrust.

  1. Sample the shape parameters
  2. Run each case on its own machine
  3. Fit a model of the results
  4. Optimize against the model

Airfoil validation

Check a solver against test data across conditions.

  1. Sweep the flow conditions
  2. Compare with the measurements
  3. Refine the grid and run again
  4. Fit a surrogate over the sweep

Daily forecast

Run a regional forecast on a schedule.

  1. Fetch the data, retrying when it is late
  2. Prepare the domain
  3. Run the model
  4. Keep the output files
