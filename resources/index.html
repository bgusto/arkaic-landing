Everything for your first run.

Install the command, run the example, and read what a job did. Tutorials are being written for the first release.

Get started

Install, sign in, and run the example sweep.

curl -fsSL https://evolve.arkaic.inc/install.sh | sh
evolve login
evolve init
evolve sweep -out f job.sh thickness=10,7,5

The command

Run evolve help for every command, and evolve help COMMAND for one. The main ones:

  • submit, sweep, sample, fit, optimize: start work
  • jobs, log, cancel: follow it
  • files, pull: download what a job kept
  • account, usage: plan, credit, and spend

Worked examples
